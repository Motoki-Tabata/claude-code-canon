# contribution-rules

## コミット
件名は `<type>: <要約>`（type は feat/fix/docs/chore）。本文は72桁で折り返す。
破壊的変更は `BREAKING CHANGE:` を本文先頭に置く。

## プルリクエスト
題名はコミット件名と同じ規則。本文に変更理由・影響範囲・確認手順を書く。
