# official-check.md（公式のドキュメントでの確認）

要件の成否が Claude Code 自体の仕様（frontmatter のキー・設定の値・ツールやコマンドの挙動・permissions の効き方など）に依存するとき、メインが `claude-code-guide` に問いを渡して公式のドキュメントで確かめ、結果をここに書く。investigator は WebFetch を持たないので、`findings.md` の `unverified` に残った仕様の論点も、ここで確かめる。仕様に依存する要件が無ければ、このファイルは作らない。

## テンプレート

```markdown
## <要件の仮の ID> <論点>
- 問い: <claude-code-guide に渡した問い>
- 答え: <公式の記述の要約。原文の引用を添える>
- 出典: <公式ドキュメントの URL と節>
- 確度: 公式で確認|確かめられなかった
- 食い違い: <要件の主張と公式が違う点。無ければ「なし」>
```

## 書き方

- 要件の `evidence` からは `investigation/official-check.md の「<見出し>」` と指す。確度が「公式で確認」の要件の根拠は、ここで読める形にする。
- 公式と食い違う主張は、要件を直してから G1 に進む。確度が「確かめられなかった」の論点を含む要件は `## 未確定` に置く。
- 公式の原文を読まずに答えを推測で書かない。独立した問いは、1つのメッセージで並列に渡す。
