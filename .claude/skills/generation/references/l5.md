# L5: Plugin

正典: `docs/L5_DISTRIBUTION.md`。この層は、`plugins` が `allowed: true` で、配布の要件があるときだけ作る。

## ディレクトリ構造

```
plugin/
├── .claude-plugin/plugin.json   マニフェスト。この中に置くのは plugin.json だけ
├── skills/<name>/SKILL.md       他のディレクトリはすべて plugin のルートに置く
├── agents/  hooks/hooks.json  .mcp.json  commands/  output-styles/  scripts/  …
```

## plugin.json

- 必須は `name` だけ（kebab-case。空白不可）。マニフェストが無くても自動発見されるが、配布するなら書く。
- コンポーネントのパス（`skills`・`commands`・`agents`・`hooks`・`mcpServers`・`outputStyles`・`lspServers`・`experimental.themes`・`experimental.monitors`）は、plugin のルートからの相対パスで、**実在しなければならない**（verify の V6）。plugin のルートの外（`../`）を指す参照は動かない。
- `skills` は既定の `skills/` に**追加**される。`commands`・`agents` などは既定を**置換**する。
- パスの変数: `${CLAUDE_PLUGIN_ROOT}`（インストール先。バージョンで変わる）・`${CLAUDE_PLUGIN_DATA}`（更新後も残る永続データ）・`${CLAUDE_PROJECT_DIR}`。
- ユーザーの設定値は `userConfig`（`sensitive: true` で keychain に保存）。`${user_config.KEY}` は shell 形式のコマンドでは使えない（exec 形式か `CLAUDE_PLUGIN_OPTION_<KEY>` の環境変数を使う）。
- `dependencies` は semver の範囲で書く。

## plugin に同梱する部品の制約

- Subagent は `hooks`・`mcpServers`・`permissionMode` が無視される（[agents.md](agents.md)）。
- `themes/`・`monitors/` は実験機能。constraints が許すときだけ。
