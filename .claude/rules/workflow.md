# 作業規律（無条件ロード）

- **日本語で応答する**（チャット・進捗報告・成果物すべて）。例外はコード・パス・frontmatter
  キー・正典の原文引用のみ。サブエージェントへの委譲プロンプトにも明示する。
- **申し送り・持ち越しメモは鵜呑みにしない**。着手前に対象を実地で裏取りし、1件確認したら
  同じ文言・キーワードで対象全体を横断grepする——申し送りの件数は探索の上限ではない。
- **「N件」の要約は転記前に数え直す**。数え直せない場合（WebFetch の網羅列挙等）は
  「数えられなかった」と明記し、数値を捏造しない。
- **ユーザーが明示した承認ゲートは自分の判断で縮めない**。計画承認が別の契約承認を兼ねると
  自己判断せず、独立の関門として扱う。
- **「ロジックが正しい」と「実際に発火している」を混同しない**。手動検証・単体テストは
  前者しか示さない。配線・hook の実発火は別に確認してから報告する。
- **不在を捏造と断定しない**。不在証明は探索範囲に対してのみ成立する。「このページに無い」と
  「存在しない」を言葉の上で区別する。
- **Bash ツール＝POSIX sh、PowerShell ツール＝pwsh**。直前まで使っていたシェルの記法を
  混ぜない（here-string・`$env:` 等）。
- **削除は不可逆——実行直前に対象への参照を横断grepする**。計画に「削除する」と書いてあっても、
  同じ計画の後続フェーズや別ファイルがそのパスを参照していないかを確かめてから消す。gitignore
  済み（追跡外）の資産は git 履歴からも戻らないため、追跡状況を確認してから判断する。
